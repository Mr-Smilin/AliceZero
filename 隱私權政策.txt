# 隱私權政策
最後更新日期：2026/08/27
本隱私權政策說明 愛麗絲（以下稱「本服務」）如何收集、使用、儲存與保護使用者資料。
使用本服務即表示你理解並同意本政策所述的資料處理方式。
1. 我們可能收集的資料
本服務可能會依功能需要，收集或處理以下 Discord 相關資料：
1.1 使用者資料
Discord 使用者 ID
使用者名稱、暱稱或顯示名稱
使用者頭像網址
使用者在伺服器中的角色資訊
使用者與 Bot 互動時輸入的指令內容
1.2 伺服器資料
Discord 伺服器 ID
伺服器名稱
頻道 ID
角色 ID
Bot 設定資料，例如語言、功能開關、權限設定
1.3 訊息與互動資料
依功能需求，本服務可能會處理：
指令內容
按鈕、選單或表單互動資料
必要的訊息 ID、頻道 ID 或伺服器 ID
錯誤紀錄與系統日誌
除非功能明確需要，本服務不會主動長期儲存完整聊天內容。
1.4 技術資料
為維護服務安全與穩定，本服務可能記錄：
錯誤訊息
指令使用時間
執行狀態
系統效能資料
防濫用相關紀錄
2. 我們如何使用資料
收集的資料可能用於以下目的：
提供 Bot 功能。
儲存伺服器設定。
處理使用者指令與互動。
維護服務穩定與安全。
偵測濫用、攻擊或違規行為。
除錯、分析錯誤與改善服務。
遵守法律、平台政策或必要的安全要求。
我們不會將使用者資料販售給第三方。
3. 資料儲存期間
資料保存期間取決於資料用途：
伺服器設定資料：不會保存伺服器設定資料。
使用者偏好或功能資料：不會保存使用者資料。
錯誤與安全紀錄：不會保存錯誤與安全紀錄，僅在發生錯誤當下印出。
臨時處理資料：僅於完成指令或功能執行所需期間內保留。
若你希望刪除相關資料，請透過本政策提供的聯絡方式提出請求。
4. 資料分享
我們不會任意分享你的個人資料。
但在以下情況下，可能會揭露或處理相關資料：
為提供服務而使用必要的基礎設施，例如主機、資料庫、日誌服務。
為遵守法律、法院命令或主管機關要求。
為調查濫用、資安事件、違反條款或保護使用者安全。
經你或伺服器管理者明確同意。
5. 第三方服務
本服務運行於 Discord 平台，並可能使用第三方基礎設施，例如：
Discord API
雲端主機服務
資料庫服務
錯誤追蹤或日誌服務
這些第三方服務可能依其自身政策處理資料。你也應閱讀 Discord 的隱私權政策與服務條款。
6. 資料安全
我們會採取合理措施保護資料安全，包括但不限於：
限制資料存取權限。
使用安全的資料儲存與傳輸方式。
避免收集不必要資料。
定期檢查服務權限與資料處理流程。
但網路服務無法保證絕對安全。若發生資料外洩或重大安全事件，我們會依合理方式通知受影響使用者或伺服器管理者。
7. 使用者權利
你可以要求：
查詢本服務是否保存與你相關的資料。
更正不正確資料。
刪除與你相關的資料。
停止使用本服務處理你的資料。
請透過下方聯絡方式提出請求。為確認身份，我們可能要求你提供必要資訊，例如 Discord 使用者 ID 或伺服器 ID。
8. 兒童與未成年人
本服務不以未滿 Discord 規定使用年齡的使用者為對象。
若你是未成年人，請在監護人同意下使用本服務。若我們得知誤收不應收集的未成年人資料，會在合理範圍內刪除相關資料。
9. 資料刪除方式
若你是伺服器管理者，可以透過以下方式刪除或要求刪除資料：
將 愛麗絲 從伺服器移除。
聯絡開發者。
收到刪除請求後，我們會在合理期間內處理，除非法律、安全或防濫用目的要求保留部分紀錄。
10. 政策變更
我們可能不定期更新本隱私權政策。更新後的版本會發布於本政策。
若你在政策更新後繼續使用本服務，即表示你理解更新後的政策內容。
11. 聯絡方式
若你對本隱私權政策或資料處理方式有任何問題請聯絡開發者。
